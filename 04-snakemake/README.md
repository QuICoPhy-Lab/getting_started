# Snakemake

This section is for automating multi-step analyses with Snakemake.

## Goal

Describe your pipeline once, then let Snakemake run only what is needed with proper dependency handling.

## Typical workflow

1. Write rules in a `Snakefile`.
2. Define inputs, outputs, and software environments.
3. Execute locally or submit to SLURM from Snakemake.

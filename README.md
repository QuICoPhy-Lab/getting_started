# Getting Started (HPC Workflow)

This repository contains short guides and templates to help you start running jobs on HPC clusters.

## Repository structure

- `01-cluster-basics/`: first connection, file transfers, and SLURM job scripts.
- `02-docker/`: building reproducible container images locally with Docker.
- `03-apptainer/`: running those images on the cluster with Apptainer.
- `04-snakemake/`: workflow automation with Snakemake.

## Recommended order

1. Start with `01-cluster-basics/README.md`.
2. Continue with `02-docker/README.md`.
3. Then `03-apptainer/README.md`.
4. Finish with `04-snakemake/README.md`.
